Workflow de Soumission

📝 Processus de Soumission de Code

1. Création

Le professeur crée un devoir avec critères et tests

→

2. Soumission

L'étudiant écrit et soumet son code via l'éditeur

→

3. Exécution

Compilation et exécution automatique du code

→

4. Évaluation

Note automatique + détection de plagiat

🔍 Système de Correction Automatique

✅ Critères d'Évaluation

  • Compilation : Le code compile-t-il ?
  • Exécution : S'exécute-t-il sans erreur ?
  • Tests : Passe-t-il les cas de test ?
  • Syntaxe : Respect des bonnes pratiques

📊 Attribution des Notes

  • 100% : Code parfait, tous tests passés
  • 0% : Erreurs de compilation/exécution
  • Partiel : Selon les tests réussis
  • Feedback : Détails des erreurs

⚡ Avantages du Système

Feedback immédiat • Correction objective • Gain de temps professeur • Apprentissage amélioré

Détection de Plagiat

🔍 Système de Détection 100% Local

🧠 Algorithme de Détection

1. Normalisation du Code
  • Suppression des espaces et commentaires
  • Standardisation de la casse
  • Élimination des variations stylistiques
2. Comparaison Ligne par Ligne
  • Analyse de similarité structurelle
  • Détection des blocs de code identiques
  • Calcul du pourcentage de similarité
3. Classification Automatique
  • Acceptable : < 30% similarité
  • Attention : 30-60% similarité
  • Suspect : > 60% similarité
