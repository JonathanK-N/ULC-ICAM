# 📋 Guide d'Utilisation - Présentation ULC-ICAM Turnin System

## 📁 Fichiers de Présentation Créés

### 1. 🖥️ Présentation Interactive HTML
**Fichier**: `presentation_ulc_icam.html`
- **Format**: Présentation web interactive (12 slides)
- **Navigation**: Clavier (flèches) ou boutons
- **Utilisation**: Ouvrir dans un navigateur web
- **Avantages**: 
  - Animations fluides
  - Navigation intuitive
  - Design moderne et professionnel
  - Adapté pour projection

### 2. 📄 Document Détaillé Markdown
**Fichier**: `presentation_detaillee.md`
- **Format**: Documentation complète en Markdown
- **Contenu**: 12 sections détaillées avec analyses techniques
- **Utilisation**: Lecture directe ou conversion PDF
- **Avantages**:
  - Contenu exhaustif et technique
  - Facilement modifiable
  - Format universel

### 3. 🔧 Générateur PDF
**Fichier**: `generate_pdf.py`
- **Format**: Script Python pour génération PDF
- **Fonction**: Convertit le Markdown en PDF professionnel
- **Utilisation**: `python generate_pdf.py`
- **Résultat**: `ULC-ICAM_Turnin_System_Presentation.pdf`

## 🚀 Instructions d'Utilisation

### Pour la Présentation Interactive

1. **Ouvrir la présentation**:
   ```bash
   # Double-cliquer sur le fichier ou
   # Ouvrir avec votre navigateur préféré
   presentation_ulc_icam.html
   ```

2. **Navigation**:
   - **Flèche droite** ou **Espace** : Slide suivante
   - **Flèche gauche** : Slide précédente
   - **Boutons** : Navigation avec la souris

3. **Mode Plein Écran** (recommandé pour présentation):
   - Appuyer sur **F11** dans la plupart des navigateurs
   - Ou utiliser le menu du navigateur

### Pour Générer le PDF

1. **Installer les dépendances** (si nécessaire):
   ```bash
   pip install markdown weasyprint pdfkit
   ```

2. **Exécuter le générateur**:
   ```bash
   python generate_pdf.py
   ```

3. **Résultat**:
   - Le PDF sera créé automatiquement
   - Ouverture automatique du fichier généré
   - Nom: `ULC-ICAM_Turnin_System_Presentation.pdf`
