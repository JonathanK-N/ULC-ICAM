Importer des utilisateurs via CSV

Format du fichier CSV :

Le fichier doit contenir les colonnes suivantes selon le type d'utilisateur :

Pour les étudiants :
username,role,cip,nom,postnom,prenom,sexe,date_naissance,promotion,faculte,telephone,email,adresse

Exemple étudiant :
etudiant1,student,CIP001,Dupont,Jean,Pierre,M,1995-05-15,L1,Faculté des Sciences et Technologies (ULC-ICAM),+243123456789,jean.dupont@ulc-icam.cd,Kinshasa
Pour les enseignants :
username,role,cip,nom,postnom,prenom,sexe,date_naissance,cours_dispenses,departement,grade,telephone,email,bureau

Exemple enseignant :
prof1,teacher,CIP002,Martin,Marie,Claire,F,1980-03-20,Mathématiques,Mathématiques & Informatique,Prof. Associé,+243987654321,marie.martin@ulc-icam.cd,Bureau 101
Seuls les fichiers .csv sont acceptés. Le système détectera automatiquement le type d'utilisateur selon les colonnes.
