Tout ce dont vous avez besoin

Une suite complète d'outils pour la gestion académique moderne.

📝

Soumission de devoirs

Dépôt de fichiers PDF, DOCX, code source avec suivi en temps réel.

🔍

Détection de plagiat

Moteur 3 niveaux : comparaison directe, structure de code et recherche web.

🤖

Correction IA

Correction automatique assistée par intelligence artificielle (OpenAI).

👥

Travail en groupes

Formation manuelle ou automatique des groupes de travail collaboratif.

💻

Exécution de code

Compilation et exécution en ligne via Judge0 (Python, C, C++, Java).

📊

Rapports & statistiques

Tableaux de bord avec métriques en temps réel pour les enseignants et admins.

📱

Progressive Web App

Accessible sur mobile, tablette et desktop. Installable comme application native.

🔐

Sécurité avancée

Mots de passe hashés, protection CSRF, rate limiting, sessions sécurisées.
